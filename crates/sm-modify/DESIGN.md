# sm-modify

Mesh modification ops (W4 tasks MOD-HTET, MOD-CONV2, MOD-REFINE-U, MOD-REFINE-L; see drafts/meshops.md): `mesh.htet` and `mesh.qtri` (hex, wedge, pyramid to tet with polyhedral closure, quad to tri), `mesh.thex` and `mesh.tquad` (tet to 4 hexes, tri to 3 quads), uniform `mesh.refine` with `LevelMap`, and (MOD-REFINE-L) `mesh.refine_local`, local refinement with polyhedral hanging faces. Region and tag edits are not here; they belong to REGIONS-* in sm-model/sm-boolean. The `modify` plugin is registered in `sm_server::standard()`.

## Pass shape (D1 core, built by MOD-REFINE-U)

Every op is a pure `MeshRead -> MeshBuild` pass: it reads the source entry, builds a NEW mesh through `MeshBuild` with new ids, inserts it with `insert_mesh` (`derived_from` set, `record_successors`), and keeps classification, sets and tags. The reusable parts live in `refine.rs`: node tables keyed by source edge / quad-face / cell index (never by hash order), a per-shape template (`template.rs`), classification of every new entity from the parent entity it lies on, and set / tag carry-over. Losses are reported as warning diagnostics with a code (`refine.set_dropped`, `refine.tag_dropped`). MOD-HTET and MOD-REFINE-L reuse the node table and the carry-over.

## `mesh.refine` (MOD-REFINE-U)

`mesh {mesh, levels?, keep_source?, project?}`. Each level is its own mesh entry (role `mesh`, coarsest first) linked fine-to-coarse by a `LevelMap` with a face map: `insert_mesh` first, then `MeshLayer::link` with `CatalogEdit` in scope. With `keep_source: false` the source goes through `retire_mesh` (its links drop) and level 1 is not linked. The `refine.report` info diagnostic carries counts, projection counters, total volume and minimum scaled Jacobian of parent and child.

Rules: tet 1 to 8 (four corner tets, the octahedron cut along its shortest diagonal, ties to the first of the three; the cut depends on coordinates only, so it needs no vertex ranks), hex 1 to 8, wedge 1 to 8 (triangle 1 to 4 times two layers), pyramid 1 to 6 pyramids + 4 tets (four corner pyramids, the top pyramid, the inverted centre pyramid and four tets at the base edges), tri 1 to 4, quad 1 to 4. A new node spans a set of parent corners and sits at their mean: edge midpoints, quad-face centres, hex centres. Polyhedra, high order, inactive and non-conformal cells are refused.

Classification: original vertices keep theirs; an edge node takes the class of its edge (the edge table of the source, or one derived with a vertex-rule fallback for edges on a model edge); a face node the face class; a cell node the cell class. A child face lying on a parent face takes that face's class (and `PartitionCut` kind), any other child face the cell's. If the source has an edge table so has the result (child half-edges of a parent edge keep its class).

Projection (`project`, default true): a new node classified on a `TopoEdge` or `TopoFace` is projected onto the carrier with `project(p, None)` (the `sm-smooth` rule: refused outside the curve range or the trimmed face). It is accepted unless an incident child cell would drop to a scaled Jacobian at or below 1e-12 (or worsen an already bad one); then the straight position stays and the counter `projection_rejected` says so. A projection that moves a node by rounding only (planar faces) keeps the straight bits.

Sets: cell sets become the children; face sets the child faces lying on the member faces; side sets the child sides whose cell descends from the member side; vertex sets the original vertices plus the new nodes lying on a covered entity: a model face (a model edge in 2D) all of whose mesh vertices are members covers its mesh faces, so their edge midpoints and face centres join, as does the midpoint of a model edge with both ends members; a wall face with all vertices members also covers when one of them lies on its model face (box-picked patches); on a model face with no interior mesh vertex (a wall one interval thick) every such wall face covers, so a corner triangle there cannot be told from a patch, and likewise the midpoint of a one-interval model edge joins when both its corner nodes are members (known ambiguities, reported as the info diagnostic `refine.set_ambiguous` naming the set and the model face or model edge: the one-interval model-edge case is reported too, and a model edge with an interior mesh vertex or a midpoint already covered by a member wall face is not); interior faces and cell centres never join (a Dirichlet node set on one wall stays on that wall, and a set on a plane that is no model face gains no new nodes). A mesh without classification falls back to boundary faces whose vertices are all members, which cannot tell walls apart. Cell tags are inherited; vertex tags take the mean (real) or the lowest spanned vertex's value (integer). Face and edge tags, shell-side and point sets are dropped with a warning.

## Measured (see `tests/`)

- Hex `n^3` block: `(2n+1)^3` vertices, `8n^3` cells, boundary Euler characteristic 2, scaled Jacobian unchanged (1); sheared parallelepipeds: each child exactly V/8 (1e-14), min and max scaled Jacobian equal the parent's (affine invariance).
- Tets: four corner children exactly V/8, the octahedron V/2; a Kuhn tet block stays in 1 similarity class for 3 levels (Freudenthal refinement is self-similar; the bound in the spec is 3).
- Pyramid: 10 children (6 pyramids, 4 tets), volumes V/8 and V/16; the 48-pyramid cube refines to 480 and validates. Wedge 8 children of V/8. Mixed hex/wedge/pyramid/tet fixture: conformal, boundary area unchanged.
- Axial cylinder `r = 1`, `h = 2`, 16 circle intervals, 240 hexes: 1920 and 15360 cells at levels 1 and 2, every lateral node at r = 1 to 1e-12, volume equal to the inscribed prism `(n/2) sin(2 pi/n) * 2` for `n = 32, 64` to 1e-12 (6.242890304516, 6.273096981092 against 6.283185307180), minimum scaled Jacobian stays 0.707107.
- W3c through pin cell (default strategy, ruling D11: the 8-node fuel disk is meshed with the O-grid, one cell, 72 hexes, 8 circle intervals): fuel volume 0.452548340 -> 0.489834793 (`pi r^2 h` = 0.502654825), relative error 9.97e-2 -> 2.55e-2 (the polygon deficit falls fourfold); total volume exact to 1e-12; cells 72 -> 576 (-> 4608 -> 36864 at levels 2 and 3), 56 nodes projected, none rejected. The minimum scaled Jacobian stays 0.7071 at every level, with projection or without, and `refine.quality` is silent. The forced-pave pin (below) is the case that halves.

## Quality and VOLFIT (b1 review)

- `refine.quality` warning: the minimum scaled Jacobian of a level fell below `QUALITY_DROP_FACTOR` (0.6) times its parent's. On the default-mesher pin cell (72 hexes, ruling D11) it never fires: the minimum is 0.7071 at levels 0 to 3. The halving applies to the forced-pave pin (`pave` forced on the fuel disk's caps, 8 circle intervals, 48 hexes), whose corner cell owns two consecutive boundary arcs: per level with projection 0.7071, 0.3827, 0.1951, 0.0980 (ratios 0.54, 0.51, 0.50), i.e. `sin(2 pi / n)` for `n = 8, 16, 32, 64` circle intervals (the interior angle is `pi - 2 pi / n`); without projection it stays 0.7071. Node placement cannot change it (all three of its nodes on the arc are fixed by the circle), so it is not a bug of the pass; a topology without such cells (the O-grid core of D11) does not have it, and smoothing cannot repair it. Disks of 6 and 7 circle nodes keep pave (D11), so they can still reach the warning.
- A level of `mesh.refine` projects the new nodes onto the circle, which grows the polygon volume toward `pi r^2 h` but does not reach it: run `mesh.preserve_volume` (VOLFIT) again after each level, since the level-1 fit is for the coarse polygon.

## `mesh.htet`, `mesh.qtri` (MOD-HTET)

`htet.rs` (pure pass), `deck.rs` (deck roots and re-verification), `convert.rs` (the ops). `mesh.htet {mesh, cell_set?, closure?, keep_source?}`, `mesh.qtri {mesh, mode?, cell_set?, keep_source?}`; `cell_set` names a cell set of the mesh (a block or a `mesh.flag_cells` group).

Rule (ruling D2, conformity by vertex ordering, no propagation): the rank of a vertex is `(root, index)` where the root is the lowest index of its deck class; every quad is cut along the diagonal through its lowest-ranked corner, so two cells sharing a quad agree without talking. A cell is cut as a cone from its lowest-ranked corner over the faces that do not contain it, each quad split by that rule: hex 6 tets, or 5 when the three far faces are all cut away from the corner opposite the lowest (then the three tets over the cap triangles around that corner are replaced by two: `(v7, n1, n2, n3)` and `(v0, n1, n2, n3)`); wedge 3; pyramid 2. **Steiner:** none of the 8! = 40320 orderings of a cube needs one (8640 give 5 tets, 31680 give 6, every tet positive, volume 1 to 1e-14), so no centroid split exists in the code. Vertices keep their indices and no point is added; unselected tets, hexes, wedges and pyramids that touch no cut quad are copied as they are.

Deck pairs: translation and rotation decks of the model give the roots (`deck.rs`: partners are found by `B = T(A)` on the vertices of the faces of the paired model faces, to `1e-9` of the mesh diagonal, grid-hashed; hidden host faces go through their live cover as in the FEM lowering). The result is re-verified (A-side faces mapped by the vertex map equal the B-side faces): `htet.report` carries `deck_pairs` and `deck_mismatch`, and a mismatch (a selection that cuts one side only) is the warning `htet.deck_mismatch`. Mirror decks are self-paired and add nothing. QTri ranks by vertex index only (deck pairs are read on volume meshes; no 2D deck test exists), THex/TQuad split every face alike by construction.

Closure: a selected cell next to an unselected one cuts the shared quad into its two triangles; the unselected neighbour keeps its other faces and becomes a `Polyhedron` with one more face per cut quad (`closure: "polyhedral"`, default). `closure: "whole"` is refused with `closure whole: cell N shares a quad with selected cell M` unless the selection is closed. Polyhedra in the source stay polyhedra; selected tets are no-ops. Inversion: every tet's signed volume is checked; a cell whose cut gives a non-positive tet (a folded face) is refused with `htet.inverted_tet` naming the cell, and nothing is written. The refusal depends on the labels: the thin hex of `tests/htet.rs::a9` (corner Jacobians all positive) cuts fine in index order and inverts under `[1, 0, 2, 5, 4, 7, 3, 6]`.

The builder derives the classes of the new edges (cut diagonals, cone interior edges); `validate` is clean with a source edge table (`a4`, `a5`). Sets, tags and the `LevelMap` (with face map: each cut triangle lies on its quad) are carried as in `mesh.refine` through the shared `Lineage` of `carry.rs` (vertex sets keep their members: no new edge or face nodes). QTri 4-split adds one centroid per quad, classified on the cell; a 2D mesh has no closure problem (edges are not split).

Quality (measured, `tests/htet.rs`, `tests/op_htet.rs`): the minimum scaled Jacobian of the tets of a unit cube is 0.4082 (1/sqrt 6) in 6-tet cuts and 0.7071 in 5-tet cuts (the hex had 1); a structured `2x2x2` meshed brick gives 48 tets with minimum 0.5774; `4x4x4` block 64 -> 384 tets (all structured cuts are 6-tet) with volume 64 exact to 1e-12; sidesets keep their area (each boundary quad is 2 triangles). Splitting good hexes costs quality: smooth afterwards, or cut only what needs it (closure). `mesh.to_poly` takes the all-tet result (dual volumes equal the volume); **note:** since W4-POLY-MIXED `to_poly` also takes mixed meshes, so the draft's "refused with NotTet until X-1" is moot, but its stitch of the 2x1x1 closure result currently fails `finish` validation (`class.dim_order`, an edge of the output classified above its face): reported to the orchestrator, not pinned here.

## `mesh.thex`, `mesh.tquad` (MOD-CONV2)

They reuse the refinement pass with a different template (`Rule::TetToHex`, `Rule::TriToQuad` in `refine.rs`/`template.rs`): THex joins each tet corner, its 3 edge midpoints, its 3 face centres and the tet centroid into a hex (4 per tet, even corner permutations keep the handedness; a right-handed check flips a left-handed tet's hexes), TQuad the corner, two edge midpoints and the centroid into a quad (3 per triangle). Every face is subdivided the same way, so the result is conformal and paired deck faces split alike. Exact volumes: V/4 per hex for any tet (affine image of the regular case, 1e-14), A/3 per quad. Measured: 3x3x3 Kuhn tet block 162 -> 648 hexes, volume 27 exact, `validate` clean, scaled Jacobian 0.4082 to 0.4666 (all positive); a displaced-vertex block (every tet different) minimum 0.2954; a right-triangle patch quads 0.6000. Mixed meshes are refused (`UnsupportedCell`). Level maps and projection as in `mesh.refine`; the report codes are `thex.report`, `tquad.report` (no `refine.quality` warning: the shape changes by design).

## `mesh.refine_local` (MOD-REFINE-L)

`local.rs` (pure pass, `refine_local`), `local_op.rs` (the op). `mesh.refine_local {mesh, cell_set | tag + threshold, levels?, balance?, keep_source?, project?}`: a new op, so `mesh.refine`'s canonical params are untouched. Selected hexes are split `levels` (1 to 3) times in one call into one new mesh linked to the source by a `LevelMap` with a face map (`insert_mesh`, then `MeshLayer::link`; `keep_source: false` retires the source, which drops the link).

Rule: every cell has a level (selected: `levels`, others 0, raised by the 2:1 balance across faces; `balance: false` refuses a jump above 1 with `Unbalanced`). A face has the level of the finer of its two cells, an edge the finest around it. A unit of the result is a leaf of a hex's `2^l` lattice. Every node is named by the source vertices it spans and their integer multilinear weights (denominator `2^9`), so two cells that meet at a node, an edge or a face name it the same way and the builder merges the shared faces: no matching code, no propagation. The boundary of a leaf is walked edge by edge; an edge whose host grid (its source edge, or the source face it crosses) is finer than the leaf gets the hanging nodes, and an outer face whose face level is finer than the leaf is replaced by its sub-quads. A leaf with only 4-vertex single faces is a `Hex`, anything else a `Polyhedron`; an unrefined cell of any shape (a wedge, pyramid or polyhedron next to a refined hex face included) keeps its shape when nothing hangs on it and becomes a polyhedron when its quad faces are split or a hanging node lands on an edge. Cells that must be refined but are not hexes are refused (`Unrefinable`).

Nodes: positions are the exact weighted means (edge midpoints, quad-face centres, the multilinear lattice points); classes follow the lowest host (edge, face, cell). Projection as in `mesh.refine`; the inversion guard covers every incident cell: the scaled Jacobian of a hex leaf, the smallest sine of the fan tets (cell centre, edge, face centre) of a polyhedron. Hanging nodes of polyhedra are projected too, so on a curved wall the neighbour's wall polygon is no longer exactly planar (`validate` accepts it). Sets: cells, faces and sides as in `mesh.refine`; a vertex set gains a new node when the node lies on an edge or quad of a boundary face of the mesh and all the source vertices it spans are members (interior face and cell nodes never join, as in `mesh.refine`; the wall-patch ambiguity rules of `mesh.refine` are not repeated here, so a set that covers only part of a wall face gains its edge midpoints only when both ends are members). Vertex tags: mean or lowest spanned value.

Measured (see `tests/local.rs`, `tests/local_io.rs`, `tests/op_local.rs`):
- 3x3x3 block, centre refined: 34 cells (16 hexes: 8 children, 8 corner neighbours; 18 polyhedra), 64 + 19 vertices, volume 27 to 1e-12, `validate` clean, no non-conformal face, every face planar to 1e-12, scaled Jacobian 1; the 6 face neighbours have 9 faces (4 of 5 vertices, 5 of 4), the 12 edge neighbours 6 faces (two of 5 vertices).
- Two levels at the centre: 6 face neighbours raised to level 1 (`balanced` 6), 7 refined cells; with `balance: false` the op refuses.
- Property test (48 cases of random selections of a 4x4x4 block, 1 or 2 levels): volume 64 to 1e-11, validate clean, no jump above 1, level map accepted, two runs bit-identical.
- `sm-rt`: 10 000 seeded rays through the 3x3x3 block with the centre refined twice: chord sum equals the box chord to 1e-12 (`tests/local_io.rs`). OpenFOAM `build_polymesh` + `check_polymesh` (the in-crate checkMesh proxy; no OpenFOAM install here) report nothing; Exodus writes 16 `HEX8` and 18 `NFACED` and reads back.
- Cylinder (r 1, h 2, 240 hexes) with the half `x <= 0` refined (`tests/op_local.rs`): 1080 cells (1040 hexes, 40 polyhedra), 88 new nodes projected, every rim and wall node at r = 1 to 1e-12, volume 6.122934918 -> 6.182912611 = the inscribed polygon `2 (8 sin(pi/16) + 4 sin(pi/8))` to 1e-12 (2 pi = 6.283185307); min scaled Jacobian 0.707107 before and after, hex edge ratio 2.057 before and after (the polyhedra's 4.114 counts their hanging half edges).
- W3c pin cell with only the fuel refined: 72 -> 324 cells (288 hexes, 36 polyhedra: the moderator ring cells at the fuel interface), every cell volume positive, `validate` clean, total volume 1.5876 (1.26^2) to 1e-12, min scaled Jacobian 0.707107 before and after, hex edge ratio 2.083 before and after, 56 nodes projected, none rejected.
- 3x3x3 block, centre refined 3 times: 512 + 6 * 64 + 12 * 8 + 8 = 1000 cells, 19 refined (18 by balance), 176 polyhedra (96 + 72 + 8 leaves that meet a finer neighbour), volume exact.
- `rt.check` is `ok` with no issue on the refined brick and `rt.locate` finds every cell centroid in its own cell (`tests/op_local.rs`).

Not covered here: balance is per call. A second `mesh.refine_local` on the result refines hexes of that mesh; a polyhedral neighbour cannot be selected, so a later call can create a face jump above 1 that its own balance cannot see (select the cells next to the first refinement too, or give a larger `levels` once). The real OpenFOAM `checkMesh` run of `tools/conformance.sh` is a gate on its own fixtures (the image `opencfd/openfoam-default:2506` is not on this host); `check_polymesh`, the in-crate proxy of its topology part, is clean.
