# sm-decomp

Library of hex block decompositions (W4 task HEX-DECOMP): given a circular or polygonal region, it produces a deterministic block layout (centre block plus rings) that the O-grid scheme and the hex pin path consume. It is pure geometry and topology data, with no plugin and no registered ops. This W4-0.2 skeleton is empty; the contents arrive with HEX-DECOMP.
