# Cubit parity checklist

Source: Coreform Cubit manual v2026.8 (quick reference + section index pages). We match **capabilities**, not syntax.
Each item maps to a crate (see `ARCHITECTURE.md`). Priority: **P0** = first vertical slice, **P1** = core parity, **P2** = full parity.

Gaps still to research (per-scheme manual pages not read yet): exact behavior of each scheme, healing commands beyond `model.heal`, boundary layers, Sculpt.

W4 rule: a row is ticked only with a test name that exists on the tree (checked with grep at the W4-INT merge). Rows that W4 did partly are split: the done part is ticked with its tests and the rest stays open.

- [x] P1 curvature sizing: opt-in size functions `curvature`, `point` and `grade`, used through the size field of `mesh.size`. The `curvature` rule is the chord-height rule: the edge size follows from the sagitta `tol`, with an angle cap. Grading is on by default at 0.5 (`grade`: a number); `grade: "off"` keeps the size exact on the carriers only, which is right for curve interval goals and wrong for tet and tri schemes (the tolerance then breaks silently: a cylinder shows a 2.44% volume deficit at `off` against 0.89% at the default grade; `sm_sizing::is_ungraded_curvature` lets a caller warn, wiring a warning into `mesh.auto` is open). `tol` bounds the sagitta of an edge, not the deviation of a triangle: the centre of an inscribed equilateral triangle sags up to about 4/3 `tol` (W4: sm-sizing tests/curvature.rs `circle_edge_size_is_the_chord_height_rule_to_1e_12`, `meshed_circle_stays_within_the_tolerance_scaled_by_the_rounded_count`, `the_default_grade_is_one_half_and_the_wall_value_is_the_rule`, `default_grade_meets_the_rule_on_the_carriers_between_samples`, `point_source_grades_exactly_on_a_box`, `ungraded_curvature_is_recognised_for_the_caller_to_warn`, `bit_identical_across_runs_and_thread_counts`; sm-mesher tests/curvature_halves.rs `both_hemispheres_are_refined_alike`)
