### W3b-SCRIPT. `sm-lang` (L4, existing crate): script record, the inverse of the parser

- **Deps:** no new dependencies. Normal deps stay sm-core, sm-op-api, serde_json, thiserror, rayon. Uses by name from sm-op-api: `Timeline` (`nodes`, `get`, `children`, `roots`, `refs`, `path_to_root`), `Head`, `Node`, `OpRecord`, `Registry` (`op_version`, `decode`, `op_names`, schemas), `Engine` (`apply_record_canonical`), `State::hash`, `batch::{is_reference, REF_PATTERN}`. Dev: sm-testkit (`strategies::config(n)`, `determinism`), existing `tests/common` demo registry. Do NOT depend on sm-engine, sm-server or any W3 crate. Read first: `LANGUAGE.md` sections 4.2-4.7, 5.1, `src/interp.rs` (argument lowering, batch lowering, `fmt_num`, the string escape set in `lexer.rs`), `src/host.rs`, `crates/sm-op-api/src/{timeline,session,batch}.rs`.
- **Why here:** the timeline already stores every op as an `OpRecord` plus the state hash it produced. sm-lang owns the language and sees `Timeline` through sm-op-api, so the printer and the recorder are pure functions of `(Registry, Timeline, Head, options)`. No I/O, no clock. Transport wiring (protocol method, server, CLI, MCP) is W3-INT, see Deferred.
- **Scope A, value and statement printer (`src/print.rs`):**
  - `pub fn print_op(reg: &Registry, rec: &OpRecord, st: Style) -> Result<String, PrintError>`: one statement, `name(arg: value, ...)`. Args follow the schema's property order, sorted by key otherwise. A key that is not a plain non-keyword identifier goes through `...{ "k": v }`. Floats use `value::fmt_num` (shortest round-trip, `.0` kept, so `1` stays an integer and `1.0` a float). Strings use only the lexer's escapes (`\n \t \r \" \\ \u{..}`) and write `\$` for any `$` followed by `{` (interpolation). Ids in id-typed schema positions (`x-entity-kind`, `EntityId` pattern) print as bare script ids via `fmt_id` (`Face#3`, carrier `GeomSurface#7`, never the ambiguous `Surface#n`); everywhere else they stay string literals.
  - `Style { Readable (default), Raw }`: `Raw` prints `name(...{json})`. Readable falls back to Raw per statement, with a `RecordNote::RawFallback { node, reason }`, when the syntax self-check below fails. The positional shorthand is never printed (explicit names only).
  - **`core.batch` records** print as `batch { let b3m0 = op(...); op(ids: b3m0.body, ...) }`. Variable names `b<batch ordinal>m<member>` are unique in the script and bound only for members that are referenced. Reverse lowering of `"$i.role[k]"` is `b.role[k]`, of an array element `"$i.role[*]"` is `b.role` (alone) or a splice (inside a longer array), of a stored `"$$x"` is the literal `"$x"`. A stored bare `"$i.role"` has no source form (the language lowers `b.role[0]` to `[0]`): `PrintError::BareReference { node, path }`, or with `normalize_refs: true` it prints `[0]` and the recording notes `RecordNote::Normalized`.
  - **Syntax self-check (always on, no registry needed):** every printed statement is lexed and parsed again and its argument expressions are evaluated by the schema-less constant evaluator. The resulting JSON must equal the record params (number kind, f64 bits except `-0.0`, string bytes, key set, array order). A mismatch is `PrintError::RoundTrip { node, path }`, never a silently wrong script.
- **Scope B, recorder (`src/record.rs`):**
  - `pub fn record_script(reg: &Registry, tl: &Timeline, head: &Head, o: &RecordOptions) -> Result<Recording, RecordError>`.
  - `RecordOptions { forks: Forks, check: Check, style: Style, normalize_refs: bool, header: bool }` (`#[non_exhaustive]`, `Default` = `Head`, `Tips`, `Readable`, false, true). `Forks { Head, Refs }`. `Check { None, Tips, Every }`.
  - `Recording { text: String, nodes: usize, statements: usize, refs: BTreeMap<String, Hash256> /*source tip per recorded ref*/, requires: Vec<Requirement>, notes: Vec<RecordNote> }`. `Requirement::Input { sha256 }` is collected from `model.import_step`-style `source: {sha256}` params anywhere in a record (the script cannot carry bytes; the project must hold them). `RecordNote` covers `RawFallback`, `Normalized`, `Migrated { node, from, to }`, `Orphans { count }`, `LargeValue { node, bytes }`.
  - **Records are migrated, not copied:** a node whose `version` differs from `reg.op_version` is printed from `decode` then `OpRecord::of` (current version) with `Migrated`. Replay equality is then per node on the re-encoded record.
  - **Forks policy `Head` (default):** the ops of `path_to_root(head node)`, root first, one statement per node. An attached head on ref `r != "main"` ends with `timeline.branch("r")` (the replay session starts on an unborn `main`, so `main` also exists at the tip: documented). An unborn or empty head gives a header-only script.
  - **Forks policy `Refs`:** the union of the root paths of every ref in `refs()` (name order), as a trie. Children sort by node hash, so output is a pure function of the timeline. Emission invariant: before the op of node X, HEAD is attached to a branch that points at `parent(X)`, or detached at it. Where a ref tip or a fork point is reached, emit `timeline.branch("<ref>")` (creates the ref at the current position and attaches) and return to the walk with `timeline.checkout("<ref>")`; the carrier of a subtree is the smallest ref name inside it. Several roots start with `timeline.checkout(empty: true)`; a source with no `main` ref also starts detached so replay creates no stray `main`. The script ends with `timeline.checkout("<head ref>")` when the source head was attached. Nodes reachable from no ref (undone work) are not recorded: `Orphans { count }`. Node hashes are never written into the script (replay uses its own `Meta`, so they differ); positions are always reached through refs, `undo` is never emitted.
  - `Check::Tips` appends `assert session.hash().state == "<64 hex>"` after the last statement of every recorded ref tip (`Every`: after every statement; `None`: nothing). The hash is the stored `Check.state` of the node, so the script verifies itself when run.
  - Header (`header: true`): `// smart-mesh script record`, the source ref and tip count, the `requires` lines (`// requires input sha256:<hex>`), and `// replay on an empty project`. No timestamps, no authors, so the text is byte-stable. Node messages are not recorded (Deferred).
- **Scope C, verification (`src/record.rs`):** `pub fn verify_recording(engine: &Engine, tl: &Timeline, head: &Head, rec: &Recording) -> Result<VerifyReport, RecordError>` parses `rec.text` and runs it in an `EngineHost` over the empty state with a recording `Host` for timeline commands. `VerifyReport { statements, refs: BTreeMap<String, RefCheck{ tip_state_equal, records_equal }> }`. A replay error names the node and the statement (`entity-not-found` on a literal id that the op accepted but the language considers dead is reported with the hint `style: Raw`).
- **Scope D, small and additive:** `Host::export_formats(&self) -> Vec<String>` (default: the four current names) so `session.export`'s format validation, `help session.export` and completion read the host's list instead of the `EXPORT_FORMATS` const in `interp.rs`. A later format (`step`, `msh4`, `h5m`) then needs no sm-lang edit. Existing hosts compile unchanged.
- **Acceptance (analytic; hashes compared bytewise; every test uses the demo registry in `tests/common` plus a new demo op `Zoo` whose params cover nested objects, arrays, i64, f64, bool, enum strings, optional fields, ids of several kinds and a free-form `serde_json::Value`):**
  1. **Value round trip (proptest, `config(n)`):** random JSON params (finite f64 by random bits, i64 extremes, strings from a set including `"` `\` `\n` `\t` `\r`, U+0000-001F, `$`, `${x}`, `\$`, astral characters, `Face#3`, `$0.body`, and keys `let`, `null`, `x-y`, `""`) print and read back equal. `1` stays integer, `1.0` stays float, `1e-7`, `1.7976931348623157e308` and `5e-324` survive.
  2. **Single op:** `model.create_brick(x: 1.5, y: 2, z: 3, name: "a b")` prints as exactly that text (golden). Ids print as `Volume#1`, `Face#2`, `GeomSurface#7`, and the printed statement lowers (via `EngineHost`) to a record equal to the original after `decode` + `OpRecord::of`.
  3. **Batch:** a stored `core.batch` with `$0.body[*]` in an array parameter, `$0.body[0]` in a scalar parameter, a spliced `["$0.a[*]", "x"]` and a stored `"$$lit"` prints as a `batch` block (golden) whose lowering is byte-identical to the stored record. Two batches in one script use distinct variable names. A bare `"$0.body"` on a Many role is `BareReference`; with `normalize_refs` it prints `[0]`, notes `Normalized`, and the state hash still matches.
  4. **Linear history, `Forks::Head`:** 12 mixed ops (including two batches and a migrated v1 record) recorded, run on a fresh session: per-node record chain equal, `Check.state` of every node equal, final `State::hash` equal, ids equal (allocation order is part of the state hash). The script ends with the `assert session.hash()` line and runs without a diagnostic.
  5. **Fork topologies, `Forks::Refs` (each: record, replay on a fresh session, compare `refs()` names, per-ref tip state hash and per-node record chain):** (a) fork in the middle of `main`; (b) a ref at an interior node of another ref (`tag`-like); (c) fork at the tip (two refs on one node); (d) nested forks three deep; (e) two roots; (f) source with no `main` (replay has no `main`); (g) head detached; (h) unborn head; (i) nodes made orphan by `undo` are counted in `Orphans` and absent from the text. Replay `refs()` has exactly the source names, plus `main` only under `Forks::Head` with a non-main head (asserted).
  6. **Head after replay:** attached source head gives the same attached ref; `Forks::Head` on a non-main head ends on that ref and the status matches (asserted, with the documented extra `main`).
  7. **Corpus:** every script in `tests/golden/run/*.smesh` and `tests/golden/parse/*.smesh` that runs without an error diagnostic is run, recorded with both policies and `Check::Every`, replayed, and equal in state hash. Failing statements in a partial run stay applied and are recorded as the nodes that exist.
  8. **Styles:** a record the printer cannot express readably (forced by a `Zoo` value that fails the self-check, and by a literal id the op accepts but the language calls dead) falls back to `Raw` with a note, and replay still matches. `verify_recording` on a hand-corrupted script (one literal changed) fails naming the statement and the node, and the failing statement had no effect.
  9. **Requirements and limits:** a record with `source: {sha256}` lists the hash in `requires` and in the header; a string over `Options::max_value_len` gives `LargeValue` with a hint to stage the input. Source size over the parse limit is `RecordError::TooLarge`.
  10. **Determinism:** the same `(timeline, head, options)` gives byte-identical text across two runs, `RAYON_NUM_THREADS=1` against default, and a timeline rebuilt from `to_files`/`from_files` (the text hash is compared with `sm_testkit::determinism::check`). Child order does not depend on insertion order (a timeline built with sibling inserts in both orders gives the same text).
  11. **Export formats hook:** a test host returning `["smsh", "step"]` accepts `session.export("a.step", format: "step")`, rejects `format: "vtu"` with the did-you-mean from its list, and `help session.export` lists `step`. The default host's text is unchanged (existing goldens untouched).
  12. Rustdoc on every public item, `cargo clippy -p sm-lang -- -D warnings`, no wall-clock gates (statement and node counts are the work counters).
- **Must NOT:** edit other crates, the root Cargo.toml, CI or docs outside `crates/sm-lang/`; write node hashes, authors, times or machine paths into the script; emit `undo`/`redo` or `at:` hashes; iterate a `HashMap`/`HashSet` into output; let child order depend on insertion order; use `unwrap` on input paths (a timeline from disk is input); change an existing golden or the meaning of any existing statement; add a statement form or a registry op (the recorder prints the language as it is); resolve or open files.
- **Deferred (state in `DESIGN.md`):**
  - `ids: bind` (print ids created by earlier statements as `let b = ...; b.body`, so a script replays on a non-empty project): needs the op outputs, which the timeline does not store, so it replays through `EngineHost`. Literal ids are exact only on an empty project.
  - Node messages and authors as comments, `Forks::All` (orphans through temporary refs), `timeline.reset`, detached-head restoration.
  - Transport and surfaces, owned by W3-INT: protocol method `script.record` (ACR below), `Server` dispatch, `smesh record [--forks head|refs] [--check ...] [--verify] [-o file]`, MCP tool `record_script`, the milestone row (run the W3b milestone script, record with `Refs`, replay in a fresh project, equal state hash and per-ref tips), PARITY update.
  - STEP writer as an export format: not this task, see `open_questions` and `risks`.
