### W3b-PRIM. `sm-model` (L2, existing): remaining Cubit primitives, transform forms, copy

**Deps:** none inside W3b. Consumes frozen `sm-geom-api` (`Cone`, `EllipticCone`, `EllipticCylinder`, `Ellipse`, `Torus`, `Sphere`, `Plane`), `sm-topo-api` (`TopoHost`/`TopologyView`, `fixtures::{torus, cone, nested_spheres}`), `sm_testkit::topo::{torus, cone, cylinder, nested_spheres}`. Owns only `crates/sm-model/` (new files `src/prim2.rs`, `src/sphere_part.rs`, `src/xform2.rs`, `src/copy.rs`; `lib.rs` registration; `DESIGN.md`; tests). The contract batch now running does not touch this task.

**Scope (all ops go through `topo_txn` + `commit_topology`; outputs use `SOLID_OUTPUTS`; every size goes through the existing `create()` guard: refused when `<= linear tolerance`, non-finite, or giving degenerate derived coordinates via `span`).**

Existing ops stay unchanged (struct literals of `Move`, `Rotate`, `CreateSphere` live in other crates' tests, e.g. `sm-boolean/tests/common/rig.rs`; do not add fields to them).

1. `model.create_frustum { height, radius, minor?, top?, center? }` (`height` positional). `radius` = bottom semi-axis along x, `minor` = bottom semi-axis along y (default `radius`), `top` = top semi-axis along x (default 0, a cone); the top y semi-axis is `top * minor / radius` (homothetic section, as Cubit). Span `z = center.z +- height/2`. Four geometry cases, one builder:
   - `top == radius` (exact equality): the existing `build_cylinder` (circular) or an `EllipticCylinder` twin with `Ellipse` edges.
   - circular, `top != radius`: `SurfaceDef::Cone`, frame origin at the LARGER end disc, `frame.z` pointing away from the other end (as `fixtures::cone`: origin on the base, `z = -z`, `half_angle = atan2(R - T, h)`; for `T > R` origin on the top disc, `z = +z`). Faces `[bottom, top, lateral]`, vertices `[bottom, top]` on the seam at `u = 0`, edges `[bottom circle, top circle, seam line]`; `Line2` pcurves (u-const, v-const iso-lines), `v` in `[-slant, 0]`.
   - `top == 0` circular: apex vertex + one `DEGENERATE` pole edge exactly as `fixtures::cone` (2 faces, 3 edges incl. the pole, 2 vertices).
   - elliptic (`minor != radius` or any `top` with it): `EllipticCone` / `EllipticCylinder` with `Ellipse` edges, same layout; `half_angle = asin((A - T) / slant)`, `slant = hypot(A - T, h)` measured in the x-z plane. `top` may exceed `radius` (inverted frustum).
2. `model.create_prism { height, sides, radius, minor?, center? }` and `model.create_pyramid { height, sides, radius, top?, minor?, center? }` (`sides` positional, integer `3..=1024`, else `Invalid`). `radius` is the CIRCUMRADIUS of the regular n-gon (Cubit: the polygon is inscribed in the circle/ellipse of that radius); vertex 0 lies on `+x`, vertices ccw seen from `+z`; `minor` scales y (`y' = y * minor / radius`). The pyramid's `top` is the top circumradius (default 0 = apex; `top == radius` is refused as `Invalid`, "use create_prism"). One builder `build_polygonal(n, r_bottom, r_top, ratio, h)` with all-`Plane` faces: prism V/E/F = 2n/3n/n+2; pyramid with apex n+1/2n/n+1; truncated 2n/3n/n+2. Face order `[bottom, top?, laterals 0..n]`; lateral i spans vertex i to i+1. Planes get exact normals from the face vertices (no tolerance fitting).
3. `model.create_torus { major, minor, center? }`: ring torus about z; `major > minor > 0` else `Invalid` (spindle/horn are refused with a message). Topology and pcurves exactly `fixtures::torus` (1 vertex, 2 closed edges, 1 face, chi 0) translated to `center`.
4. `model.create_sphere_part { radius, inner?, octants?, center? }` (general form of `create_sphere`; `create_sphere` is unchanged and may delegate to the same builder when no option is set, keeping its hash). `inner` in `(0, radius)`: cavity radius. `octants: { x?, y?, z? }`, each `"positive" | "negative"`, keeps the half-space on that side of the coordinate plane through `center`; k cuts keep a hemisphere (k=1), a quarter (k=2) or an octant (k=3). The kept sphere patch is always a (u, v) rectangle of the standard sphere parametrization (u in multiples of pi/2, v in `[-pi/2, 0]`, `[0, pi/2]` or full), with pole sides as `DEGENERATE` edges and a seam only when u is full. Cap faces are `Plane`s (full discs, half discs, quarter discs, or annuli/half/quarter annuli with `inner`); caps share the axis/diameter edges. Expected cell counts `[V, E incl. degenerate, F, volumes, bodies]` for `inner = None`: none `[2,3,1,1,1]`; z `[2,3,2,1,1]`; x or y `[2,4,2,1,1]`; xy `[2,5,3,1,1]`; xz or yz `[3,5,3,1,1]`; xyz `[4,7,4,1,1]`; euler 2 for all k >= 1. With `inner`: k=0 is ONE volume with an `Outer` shell and a `Void` shell (inner sphere face, `Side::Right`), counts `[4,6,2,1,1]`, euler 4; k >= 1 is one `Outer` shell of outer patch, inner patch (reversed) and annular caps, euler 2. Outputs: the usual roles plus no extras.
5. `model.move_to { entities, to, anchor? }`: `to` is `[Option<f64>; 3]` (null component = unchanged) OR an entity id (`vertex` point, `curve`/`surface`/`volume` centroid via `model.measure` machinery); `anchor` is `"centroid"` (default, of the selection's volumes) or `"bbox_center"`. Computes `delta = to - anchor` and runs the same `apply_similarity` path as `model.move` (same refusals: meshed, shared). Outputs role `volumes`.
6. `model.rotate_about { entities, angle_deg, axis?, origin?, vertices?, face? }`, EXACTLY ONE of the three forms, else `Invalid`: `axis` (a vector, or the strings `"x"|"y"|"z"`; pivot `origin` default the world origin); `vertices: [a, b]` (axis from vertex a to vertex b, pivot a; a == b within tolerance is `Invalid`); `face` (axis = the outward unit normal of the face with the carrier sense applied, pivot = the face centroid; planar faces use the plane normal, curved faces the normal at the surface projection of the centroid, pivot that point). `origin` overrides the pivot of the 2nd and 3rd form. Right-hand rule about the axis direction. Reuses `Transform::rotation` through `apply_similarity`. Role `volumes`.
7. `model.copy { entities, count?, xform? }`: `count` in `1..=4096` (default 1). `xform` is a tagged enum `{ "kind": "move", delta } | { "kind": "rotate", angle_deg, axis?/origin?/vertices?/face? (same forms as 6) } | { "kind": "scale", factor, origin? } | { "kind": "reflect", normal, origin? }` (default none: coincident copies, allowed). Copy k (1-based) equals the source transformed by `xform` applied k times (k = 1..=count), the Cubit "repeat" pattern. Implementation: deep-copy the downward closure of the selection in ascending id order into fresh vertices, edges (flags kept, `DEGENERATE` included), faces (inner loops, pcurves, carrier senses), volumes (shell rings, kinds, sides), curves and surfaces (`curve_def`/`surface_def` cloned into new handles), tolerance overrides, then run the existing `transform_cells` (make it `pub(crate)`) on the new closure with the composed `Xf`. Sharing inside the selection is preserved (two merged bricks copy as two volumes sharing one face); sharing with unselected volumes is NOT (the copy owns its own cells, so copying one volume of a merged pair is legal, unlike move). Each selected body gets one new body holding the copies of its volumes; a bare volume gets its own new body per copy. Meshes, colors, groups, boundary kinds, decks and decomposition records are NOT copied (documented; a later `model.copy_attributes`). Roles `volumes` and `bodies` (all copies, ascending). `record_created` on every new cell; no lineage link to the source.
8. Registration in `ModelPlugin`: `model.create_frustum`, `model.create_prism`, `model.create_pyramid`, `model.create_torus`, `model.create_sphere_part`, `model.move_to`, `model.rotate_about`, `model.copy`.
